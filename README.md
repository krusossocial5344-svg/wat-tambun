# ระบบทำบุญวัด (Firebase + Vercel)

เว็บรับบันทึกการทำบุญของวัด แยกตามงานบุญ ประเภท และปี ยอดอัปเดตทันทีทุกเครื่อง แชร์ลิงก์เฉพาะงานได้ และบันทึกว่าผู้ทำบุญต้องการใบอนุโมทนาหรือไม่

- **หน้าเว็บ:** ไฟล์ธรรมดา (`index.html`, `style.css`, `app.js`) ไม่ต้อง build ใด ๆ วางบน Vercel ได้เลย
- **ข้อมูลและการเข้าสู่ระบบ:** Firebase (Firestore + Google Sign-in)
- **สิทธิ์:** ล็อกจริงที่ฐานข้อมูลด้วยไฟล์ `firestore.rules`

## สิทธิ์ผู้ใช้

| | แอดมิน | เจ้าหน้าที่ | คนทั่วไป (เปิดลิงก์) |
|---|---|---|---|
| ดูงานบุญ ยอด และรายนาม | ✓ | ✓ | ✓ (ไม่ต้องเข้าสู่ระบบ) |
| บันทึกภาพยอด | ✓ | ✓ | ✓ |
| เพิ่มรายชื่อผู้ทำบุญ | ✓ | ✓ | – |
| ดูว่าใครขอใบอนุโมทนา | ✓ | ✓ | – |
| ตรวจสลิปโอนเงิน | ✓ | ✓ | ส่งสลิปได้ |
| ดูข้อมูลใบอนุโมทนา (เลขผู้เสียภาษี ที่อยู่) / ปิดคำขอ / ลบรายชื่อ | ✓ | – | – |
| งานบุญ บัญชี เจ้าหน้าที่ ตั้งค่า รายงาน PDF/Excel | ✓ | – | – |

## โหมดตัวอย่าง
ถ้ายังไม่ได้ใส่ค่าในไฟล์ `firebase-config.js` เว็บจะเปิดใน **โหมดตัวอย่าง** อัตโนมัติ
- ใช้ข้อมูลตัวอย่างที่เก็บไว้ในเครื่องที่เปิดเท่านั้น
- มีแถบด้านบนให้สลับดูในฐานะแอดมิน เจ้าหน้าที่ หรือผู้ชมทั่วไป
- เหมาะสำหรับลองหน้าตาก่อนเชื่อม Firebase จริง

## ความสามารถหลัก
- **หน้าแรกต้อนรับ:** เปิดเว็บแล้วเจอตราวัด ชื่อวัด ปุ่ม “เข้าสู่ระบบทำบุญ” และงานบุญที่เปิดรับ ลิงก์แชร์งานบุญและแอปที่ติดตั้งแล้วจะข้ามหน้านี้ไปเลย ตราวัดเปลี่ยนได้ที่เมนูตั้งค่าวัด (ไฟล์เริ่มต้นอยู่ที่ `icons/logo.webp`)
- **แยกตามปี:** เลือกปีจากเมนูซ้าย (หรือแถบปีบนมือถือ) จะเห็นเฉพาะงานบุญของปีนั้น แต่ละงานแสดงยอดของตัวเอง ไม่มียอดรวมของวัดบนหน้าเว็บ
- **บันทึกผู้ทำบุญ:**
  - กรอกได้ทีละหลายคน บันทึกอัตโนมัติ
  - เขียนชื่อด้วยปากกาบน iPad/แท็บเล็ตได้ (ปุ่มรูปปากกา)
  - เจ้าหน้าที่หลายคนบันทึกพร้อมกันได้ และเห็นว่าใครกำลังใช้งานอยู่
- **ใบอนุโมทนา:**
  - ติ๊ก “ใบอนุโมทนา” แล้วกรอกชื่อในใบ เลขผู้เสียภาษี และที่อยู่
  - คำขอจะไปที่เมนู “ใบอนุโมทนา” ซึ่งเห็นเฉพาะแอดมิน เพื่อนำไปออกใบในระบบ e-Donation ของกรมสรรพากร แล้วใส่เลขอ้างอิงเพื่อปิดคำขอ
- **ทำบุญผ่าน QR พร้อมเพย์ และส่งสลิป:**
  - บัญชีที่ใส่เลขพร้อมเพย์จะแสดงคิวอาร์ให้สแกน
  - ผู้ทำบุญส่งสลิปผ่านหน้าเว็บได้ สลิปไปที่เมนู “ตรวจสลิป” เจ้าหน้าที่ตรวจแล้วกดยืนยัน รายชื่อจึงขึ้นในรายนาม
- **รายงาน PDF:** เลือกรายวัน รายเดือน รายปี หรือทั้งหมด จะเลือกเฉพาะงานบุญเดียวก็ได้ ส่งออกเป็น Excel ได้ด้วย
- **ประวัติการแก้ไข:**
  - ทุกการเพิ่ม แก้ไข ลบ ยืนยันสลิป ออกใบ และปิดยอด ถูกบันทึกพร้อมชื่อคนทำและเวลา
  - กฎฐานข้อมูลห้ามแก้หรือลบประวัติ แม้แต่แอดมิน
  - แก้ไขรายการต้องใส่เหตุผลทุกครั้ง
- **วิธีรับเงินและปิดยอดประจำวัน:**
  - ทุกรายการระบุได้ว่าเป็นเงินสด โอน หรือ QR
  - เมนู “ปิดยอด” สรุปยอดของเจ้าหน้าที่แต่ละคน ให้กรอกเงินสดที่นับได้จริง ระบบจะบอกว่าตรงกัน ขาด หรือเกิน
- **สำรองข้อมูล:** ดาวน์โหลดไฟล์สำรองได้ที่เมนูตั้งค่าวัด กู้คืนได้จากหน้านำเข้าข้อมูล ถ้าไม่ได้สำรองเกิน 30 วัน ระบบจะเตือนแอดมิน
- **กันสลิปซ้ำและสแปม:**
  - เตือนเมื่อรูปสลิปซ้ำ หรือยอดและวันที่ตรงกับรายการอื่น
  - ฟอร์มส่งสลิปมีตัวกันบอท และจำกัดไม่เกิน 3 ใบใน 10 นาทีต่อเครื่อง
  - เปิด App Check เพิ่มได้ (ดูหัวข้อด้านล่าง)
- **โหมดจอใหญ่:**
  - ปุ่ม “โหมดจอใหญ่” ในหน้างานบุญ ใช้เปิดบนทีวีหรือโปรเจกเตอร์ในศาลา
  - ยอดวิ่งขึ้นแบบเรียลไทม์ มีป้าย “ขออนุโมทนาบุญ” พร้อมพลุกระดาษเมื่อมีคนทำบุญ และแสดง QR ให้สแกน
  - ลิงก์แบบ `/#tv-รหัสงาน` เปิดได้โดยไม่ต้องเข้าสู่ระบบ
- **ใบอนุโมทนาบัตร (ที่ระลึก):** พิมพ์ทีละใบจากปุ่ม ⋯ ในรายชื่อ หรือพิมพ์ทั้งหมดจากหน้ารายงาน เป็น PDF ขนาด A5 ตั้งชื่อผู้ลงนามได้ในเมนูตั้งค่าวัด
- **ค้นหาและเติมชื่ออัตโนมัติ:** พิมพ์ชื่อแล้วมีชื่อเดิมให้เลือก เมนู “ค้นหาผู้ทำบุญ” ดูประวัติการทำบุญทุกปีได้
- **ติดตั้งเป็นแอป:** มีปุ่ม “ติดตั้งแอป” ท้ายเว็บ บน iPhone ใช้ Safari แล้วกด แชร์ → เพิ่มไปยังหน้าจอโฮม

- **ส่วนหัวและส่วนท้าย:** ชื่อวัด คำโปรย ที่อยู่ เบอร์โทร และ Facebook ตั้งได้ที่เมนู “ตั้งค่าวัด”

## ติดตั้งครั้งแรก

### 1. สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com แล้วกด **Add project** ตั้งชื่อ เช่น `wat-tambun` (ไม่ต้องเปิด Google Analytics ก็ได้)
2. เมนู **Build → Firestore Database** → **Create database**
   - เลือก location `asia-southeast1 (Singapore)`
   - เลือก **Start in production mode**
3. เมนู **Build → Authentication** → **Get started** → แท็บ **Sign-in method** → เปิด **Google**, **Email/Password** และ **Anonymous**
   - Email/Password ใช้กับเจ้าหน้าที่ที่ไม่มีอีเมล แอดมินออก “รหัสเจ้าหน้าที่” 8 ตัวให้ที่เมนูเจ้าหน้าที่ ใส่รหัสอย่างเดียวก็เข้าได้ (ไม่ต้องเปิด Email link)
   - Anonymous ใช้ตอนผู้ทำบุญส่งสลิป ระบบเข้าสู่ระบบแบบนิรนามให้เองเบื้องหลัง ผู้ทำบุญไม่ต้องทำอะไร และใช้จำกัดจำนวนสลิปต่อเครื่องที่ฝั่งเซิร์ฟเวอร์

### 2. ใส่กฎความปลอดภัย
1. เปิดไฟล์ `firestore.rules` แก้ `ใส่อีเมลแอดมิน@gmail.com` เป็นอีเมล Google ของแอดมิน
2. ใน Firebase ไปที่ **Firestore Database → Rules** ลบของเดิม วางเนื้อหาไฟล์ `firestore.rules` ทั้งหมด แล้วกด **Publish**
3. สร้างดัชนี (index) 3 ตัวตามไฟล์ `firestore.indexes.json` ที่ **Firestore Database → Indexes → Composite → Create index** (Query scope: Collection)
   | Collection | ฟิลด์ที่ 1 | ฟิลด์ที่ 2 |
   |---|---|---|
   | `donations` | `campaignId` Ascending | `createdAt` Descending |
   | `donations` | `campaignId` Ascending | `date` Ascending |
   | `slips` | `status` Ascending | `createdAt` Descending |
   - ถ้าใช้ Firebase CLI สั่ง `firebase deploy --only firestore` ได้ทีเดียวทั้งกฎและดัชนี
   - ถ้าลืมสร้าง หน้าเว็บจะขึ้นข้อความเตือน และใน Console ของเบราว์เซอร์จะมีลิงก์สร้างดัชนีให้กดได้เลย

### 3. เชื่อมหน้าเว็บกับ Firebase
1. ใน Firebase กดรูปเฟือง **Project settings** → เลื่อนลงที่ **Your apps** → กดไอคอน `</>` (Web) → ตั้งชื่อ → **Register app**
2. คัดลอกค่าใน `firebaseConfig` มาใส่ในไฟล์ `firebase-config.js`
3. ในไฟล์เดียวกัน แก้ `ADMIN_EMAILS` เป็นอีเมลแอดมิน (ให้ตรงกับข้อ 2)

### 4. ขึ้น GitHub แล้วเชื่อม Vercel
1. สร้าง repository ใหม่บน GitHub เช่น `wat-tambun` แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. เข้า https://vercel.com → **Add New → Project** → เลือก repository นี้
3. Framework Preset เลือก **Other** ไม่ต้องตั้งค่า build แล้วกด **Deploy**
4. ได้ที่อยู่เว็บ เช่น `wat-tambun.vercel.app`

### 5. อนุญาตโดเมน Vercel ให้เข้าสู่ระบบได้
Firebase → **Authentication → Settings → Authorized domains** → **Add domain** → ใส่ `wat-tambun.vercel.app` (ชื่อที่ได้จาก Vercel)

### 6. ย้ายข้อมูลจากระบบเดิม
1. เปิดเว็บ แล้วกด **เข้าสู่ระบบด้วย Google** (ปุ่มอยู่ล่างสุดของหน้า) ด้วยบัญชีแอดมิน
2. ไปที่เมนู **ตั้งค่าวัด** → **ไปหน้านำเข้าข้อมูล**
3. เลือกไฟล์ `data/ข้อมูลจากระบบเดิม.json` แล้วกด **นำเข้าข้อมูล**
   - ถ้าไม่ต้องการงานตัวอย่าง ให้ติ๊ก “ข้ามงานบุญตัวอย่าง” ก่อนกด
   - กดนำเข้าซ้ำได้ ข้อมูลจะไม่ซ้ำ

### 7. เพิ่มเจ้าหน้าที่
เมนู **เจ้าหน้าที่** → เลือก **ออกรหัสเจ้าหน้าที่** (สำหรับคนไม่มีอีเมล) หรือ **ใช้อีเมล Google** → **เพิ่ม**
- รหัสที่ระบบสุ่มให้แสดงครั้งเดียว กด “คัดลอกข้อความส่ง LINE” ส่งให้เจ้าหน้าที่ได้เลย
- ถ้าลืมรหัสหรือรหัสหลุด ให้แอดมินกด “ยกเลิกรหัส” แล้วออกรหัสใหม่
จากนั้นให้เจ้าหน้าที่เปิดเว็บแล้วเข้าสู่ระบบด้วยอีเมลนั้น

## (ไม่บังคับ) กันบอทด้วย App Check
1. สร้าง reCAPTCHA v3 site key ที่ https://www.google.com/recaptcha/admin โดยใส่โดเมน vercel ของวัด
2. Firebase → **App Check** → ลงทะเบียนเว็บแอปด้วย reCAPTCHA v3 (ใส่ secret key)
3. ใส่ site key ใน `firebase-config.js` ที่ `RECAPTCHA_SITE_KEY` แล้ว push ขึ้น GitHub
4. ลองใช้งาน 1–2 วัน ถ้าไม่มีปัญหา ค่อยกด **Enforce** สำหรับ Firestore

## การใช้งานประจำวัน
- **บันทึกผู้ทำบุญ:** กด “+ บันทึกผู้ทำบุญ” ที่งานบุญ แล้วกรอกได้หลายคนต่อกัน
  - ติ๊กช่อง **ใบอนุโมทนา** ถ้าผู้ทำบุญต้องการรับใบ
  - บันทึกอัตโนมัติเมื่อหยุดพิมพ์ 3 วินาที หรือกด “บันทึกทั้งหมด”
  - ถ้าอินเทอร์เน็ตหลุด ข้อมูลจะเก็บไว้ในเครื่องก่อน แล้วส่งขึ้นเองเมื่อกลับมาออนไลน์
- **ใบอนุโมทนา:** ในหน้างานบุญ กดปุ่ม “เฉพาะผู้ขอใบอนุโมทนา” เพื่อดูรายชื่อที่ต้องออกใบ เมื่อออกแล้วแอดมินติ๊กเพื่อเปลี่ยนสถานะเป็น “ออกแล้ว”
- **แชร์:** ปุ่ม “แชร์งานนี้” ให้ลิงก์ เช่น `https://wat-tambun.vercel.app/#c123` คนที่เปิดลิงก์จะเห็นเฉพาะงานนั้น
- **ส่งออก Excel:** ปุ่มส่งออกจะได้ไฟล์ .csv ซึ่งมีคอลัมน์ “ต้องการใบอนุโมทนา” และ “สถานะใบอนุโมทนา” ด้วย

## แก้ไขเว็บภายหลัง
เมื่อแก้ไฟล์ ให้เปลี่ยนเลขเวอร์ชัน `V` ในไฟล์ `sw.js` ด้วย เครื่องที่ติดตั้งแอปไว้จะได้โหลดของใหม่
แก้ไฟล์ใน GitHub (หรือ push จากเครื่อง) แล้ว Vercel จะ deploy ให้อัตโนมัติ ส่วนข้อมูลอยู่ใน Firebase จึงไม่หายเมื่อแก้หน้าเว็บ

## ข้อควรรู้
- รายนามและยอดเงินเป็นข้อมูลสาธารณะ (อ่านได้โดยไม่ต้องเข้าสู่ระบบ) เพื่อให้ลิงก์แชร์ทำงาน
  - ตัวเลือก “ซ่อนจำนวนเงิน” ซ่อนแค่บนหน้าเว็บ ผู้มีความรู้ทางเทคนิคยังดึงตัวเลขได้
  - **อย่าใส่ข้อมูลส่วนตัว** เช่น เลขบัตรประชาชน ที่อยู่ หรือเบอร์โทร ในช่องหมายเหตุ
- รูปสลิปและลายมือชื่อเก็บใน Firestore แบบย่อขนาดแล้ว ไม่ต้องใช้ Firebase Storage จึงใช้แพ็กเกจฟรีได้
- Firebase แพ็กเกจฟรี (Spark) อ่านได้วันละ 50,000 ครั้ง และเขียนได้วันละ 20,000 ครั้ง ระบบออกแบบให้อ่านน้อยที่สุด
  - หน้ารวมงานบุญและหน้าแรก ใช้ยอดสรุปจากเซิร์ฟเวอร์ (นับ 1 ครั้งต่อรายชื่อ 1,000 รายการ) ไม่โหลดรายชื่อ
  - หน้างานบุญของคนทั่วไป โหลดรายนามล่าสุด 60 รายการ กด “ดูรายนามเพิ่ม” ได้
  - เจ้าหน้าที่โหลดรายชื่อครบเฉพาะงานที่เปิดอยู่ ส่วนรายงาน ค้นหา และสำรองข้อมูล โหลดทั้งหมดเมื่อเปิดหน้านั้นเท่านั้น
  - หน้าตรวจสลิปโหลดเฉพาะสลิปที่รอตรวจ ส่วนที่ตรวจแล้วโหลด 20 ใบล่าสุดเมื่อกดแท็บ
- กันสแปมสลิปที่ฝั่งเซิร์ฟเวอร์ (กฎ Firestore): เครื่องเดียวส่งได้ 1 ใบต่อนาที และไม่เกิน 10 ใบต่อ 24 ชั่วโมง ถ้าต้องการกันเข้มขึ้นให้เปิด App Check ด้านบน
- ความเป็นส่วนตัว (PDPA): หน้าส่งสลิปแจ้งชัดว่าชื่อจะแสดงต่อสาธารณะ มีตัวเลือก “ไม่ประสงค์ออกนาม” (ชื่อจริงเห็นเฉพาะเจ้าหน้าที่) และมีหน้า “นโยบายความเป็นส่วนตัว” ที่ส่วนท้ายเว็บ เจ้าหน้าที่พิมพ์ “ผู้ไม่ประสงค์ออกนาม” ได้จากรายชื่อแนะนำ
- ช่องชื่อผู้ทำบุญขยายความสูงตามความยาวชื่อ (ไม่เกิน 200 ตัวอักษร) จึงเห็นชื่อยาวได้ครบทั้งตอนพิมพ์และในรายนาม
